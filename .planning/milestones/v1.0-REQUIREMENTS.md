# Requirements: Minerva Money

**Defined:** 2026-03-22
**Core Value:** Accurate, auto-synced financial data with envelope budgeting that lets you see where every dollar goes and how spending trends over time.

## v1 Requirements

Requirements for initial release. Each maps to roadmap phases.

### Data Sync

- [x] **SYNC-01**: App syncs transactions from SimpleFIN with deduplication (transactionId primary, hash fallback)
- [x] **SYNC-02**: App runs scheduled auto-sync twice daily
- [x] **SYNC-03**: User can trigger a manual sync via "Sync Now" button
- [x] **SYNC-04**: App displays sync status indicator showing last sync time and any errors
- [x] **SYNC-05**: App logs sync failures server-side for debugging

### Accounts

- [x] **ACCT-01**: User can view all linked accounts with current balances on the dashboard
- [x] **ACCT-02**: App records daily balance snapshots per account for historical tracking
- [x] **ACCT-03**: App displays investment accounts as balance-only for net worth calculation
- [x] **ACCT-04**: User can view transaction list with filtering by date, payee, amount, and category
- [x] **ACCT-05**: User can search transactions by payee or memo text

### Budgeting

- [x] **BUDG-01**: User can create and manage budget categories organized into category groups
- [x] **BUDG-02**: User can allocate money to envelope categories for each monthly period
- [x] **BUDG-03**: Unspent envelope balances roll forward to the next month automatically
- [x] **BUDG-04**: Overspent categories deduct from next month's available-to-budget funds
- [x] **BUDG-05**: User can set default monthly allocation per category
- [x] **BUDG-06**: App auto-populates envelope allocations on the 15th and last day of each month using defaults
- [x] **BUDG-07**: User can manually override any auto-populated allocation

### Categorization

- [x] **CATG-01**: User can manually assign a category to any transaction
- [x] **CATG-02**: User can create categorization rules matching on merchant name, amount range, and/or memo text
- [x] **CATG-03**: Rules apply retroactively to all existing matching transactions when created
- [x] **CATG-04**: Rules apply automatically to all future matching transactions
- [x] **CATG-05**: When multiple rules match, the most specific rule wins (ties: newer wins)
- [x] **CATG-06**: User can split a single transaction across multiple categories
- [x] **CATG-07**: App auto-suggests transfer pairs by matching offsetting transactions across accounts
- [x] **CATG-08**: User can manually confirm or link transfer pairs
- [x] **CATG-09**: Confirmed transfers are excluded from budget and spending reports

### Reporting

- [x] **REPT-01**: User can view spending by category as pie/bar charts, filterable by date range
- [x] **REPT-02**: User can view spending trends over time as line charts showing month-over-month patterns
- [x] **REPT-03**: User can view net worth trend as a line chart over time

### Transactions

- [x] **TXNR-01**: User can manually enter a transaction (amount, payee, date, category, account)

### Infrastructure

- [x] **INFR-01**: App performs atomic SQLite backups to iCloud Drive every 6 hours via launchd
- [x] **INFR-02**: App triggers SQLite backup after every SimpleFIN sync completion
- [x] **INFR-03**: App retains 30 days of timestamped backup snapshots plus a latest copy
- [x] **INFR-04**: All money values are stored as integers (cents) to avoid floating-point errors

## Out of Scope

| Feature | Reason |
|---------|--------|
| Multi-user / authentication | Single user on private home server — unnecessary complexity |
| Mobile native app | Web UI is responsive and accessible from any device on the network |
| Investment portfolio tracking | Balance-only needed for net worth; portfolio detail is enormous scope |
| AI/ML categorization | Rules engine is deterministic and debuggable; ML requires training data and model hosting |
| Recurring transaction forecasting | Real transactions arrive via bank sync; predictions add complexity without value |
| Goal tracking / savings targets | Envelope categories serve this purpose (e.g., "Vacation Fund" with rollover) |
| Credit card payment categories | Credit card payments are transfers between accounts; spending tracked at charge time |
| Bill calendar view | Duplicates what bank sync provides; more UI surface to maintain |
| Cryptocurrency tracking | Out of scope for user's financial picture |
| Push notifications / email alerts | In-app indicator sufficient for single user |
| Freedom Mortgage direct connection | Payment appears as bank debit from linked account |
