    3. Add two mutations:
       - `setDefaultMut` calling `trpc.budget.defaults.set.mutationOptions(...)` with onSuccess invalidating `trpc.budget.defaults.list` query key, and onError setting errorMessage with 3s timeout.
       - `deleteDefaultMut` calling `trpc.budget.defaults.delete.mutationOptions(...)` with same onSuccess/onError pattern.

    4. Add a `handleSetDefault(categoryId: number, cents: number)` function: if cents === 0, call deleteDefaultMut.mutate({ categoryId }), else call setDefaultMut.mutate({ categoryId, amount: cents }).

    5. Pass `defaultsMap` down to `BudgetGroup`:

       - Update `groupCategories()` to accept the defaults map and compute `totalDefault` for each group by summing `defaultsMap.get(cat.categoryId) ?? 0` for each category.

    6. Update ALL grid layouts from `grid-cols-4` to `grid-cols-5` (three places: column headers div, group header div, category row div).

    7. Add column header "Default" between "Category" and "Allocated" in the headers div.
