  <behavior>
    - createBackup(db) writes a timestamped backup to the iCloud Drive MinervaBackups directory
    - Backup file named `minerva_YYYYMMDD_HHMMSS.db`
    - After backup, copies to `minerva_latest.db` in same directory
    - After backup, runs PRAGMA integrity_check on the backup file and throws if not 'ok'
    - Prunes backup files older than 30 days from the backup directory
    - Creates backup directory if it doesn't exist
    - Returns a result object with backup path, size, and integrity status
    - Function is exported and callable programmatically (for INFR-02 post-sync use in Phase 2)
  </behavior>
  <implementation>
    1. Create `packages/server/src/backup/backup.ts`:
       - `createBackup(db: Database.Database, backupDir?: string): Promise<BackupResult>`
       - Default backupDir: `~/Library/Mobile Documents/com~apple~CloudDrive/MinervaBackups/`
       - Steps:
         a. Ensure backupDir exists (`fs.mkdirSync(backupDir, { recursive: true })`)
         b. Generate timestamp: `YYYYMMDD_HHMMSS` format
         c. Call `await db.backup(path.join(backupDir, \`minerva_${timestamp}.db\`))`
         d. Copy timestamped backup to `minerva_latest.db` using `fs.copyFileSync`
         e. Open backup file with better-sqlite3, run `PRAGMA integrity_check`, close
         f. If integrity_check result is not 'ok', throw an error
         g. Prune: list files matching `minerva_*.db` (but not `minerva_latest.db`), delete those with mtime > 30 days
         h. Return `{ path, timestamp, sizeBytes, integrityOk: true }`
       - Export `BackupResult` type from the module

    2. Create `packages/server/src/backup/backup.test.ts`:
       - Use temp directories for both source DB and backup target
       - Test: backup creates timestamped file in target directory
       - Test: minerva_latest.db is created alongside timestamped backup
       - Test: backup passes integrity check
       - Test: old backups (>30 days) are pruned
       - Test: backup directory is created if missing
       - Test: function returns correct BackupResult shape
       - Clean up temp files in afterEach

    3. Create `com.minerva.backup.plist` (launchd plist) at project root:
       - Label: `com.minerva.backup`
       - ProgramArguments: `["/usr/local/bin/node", "{project_path}/packages/server/src/backup/run-backup.ts"]`
         (Note: actual path will be configured at install time)
       - StartInterval: 21600 (6 hours in seconds)
       - RunAtLoad: true
       - StandardOutPath/StandardErrorPath: `~/Library/Logs/minerva-backup.log`

       This file is created but NOT loaded (loading is out of scope per CONTEXT.md deferred items).
  </implementation>
</feature>
