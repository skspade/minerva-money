1. Create `packages/client/src/trpc.ts` — the tRPC React integration:
```typescript
import { createTRPCContext } from '@trpc/tanstack-react-query';
import type { AppRouter } from '@minerva/server';

```
NOTE: If `@minerva/server` type import fails due to module resolution, use a relative path: `import type { AppRouter } from '../../server/src/sync/trpc-router.js'`. Try the workspace import first.

2. Create `packages/client/src/main.tsx` — React root with all providers:
- Create a QueryClient instance (no SSR needed, simple `new QueryClient()`)
- Create tRPC client with `createTRPCClient<AppRouter>` and `httpBatchLink({ url: '/trpc' })`
- Wrap in `<QueryClientProvider>` then `<TRPCProvider>` then `<App />`
- Use `ReactDOM.createRoot(document.getElementById('root')!)` to mount

3. Create `packages/client/src/app.tsx` — Router and route definitions:
- Use `<BrowserRouter>` from `react-router` (NOT react-router-dom)
- Define `<Routes>` with a parent `<Route element={<Layout />}>` containing:
  - `<Route index element={<AccountsPage />} />` (default route shows accounts)
  - `<Route path="accounts" element={<AccountsPage />} />`
  - `<Route path="transactions" element={<TransactionsPage />} />`
- For now, create simple placeholder components for AccountsPage and TransactionsPage that render a heading (they will be replaced in plans 02 and 03)

4. Create `packages/client/src/components/Layout.tsx` — Persistent layout:
- Top navigation bar with Tailwind styling: `bg-gray-900 text-white` or similar dark header

- Navigation links using `<NavLink>` from react-router: "Accounts" and "Transactions"
- Active link gets a visual indicator (underline or different background)
- Right side: placeholder for sync status (will be filled by plan 04)
- Main content area with `<Outlet />` from react-router below the nav
- Basic page padding and max-width for the content area
