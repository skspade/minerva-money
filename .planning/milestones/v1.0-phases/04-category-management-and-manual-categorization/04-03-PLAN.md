    **Update TransactionsPage.tsx:**

    1. Replace the hardcoded "Uncategorized" text in the category column with a `CategoryPicker` component for each row. Pass `value={txn.categoryId}` and an `onChange` handler that calls the `updateCategory` mutation.

    2. Add an optimistic update for category assignment:
       - Use `useMutation` wrapping `trpc.transactions.updateCategory.mutate`
       - `onMutate`: cancel queries, snapshot previous data, optimistically update the transaction's categoryId, categoryName, and groupName in the cache. To get the category/group name for the optimistic update, look up the selected category from the cached `categories.groups.list` query data.
       - `onError`: rollback to snapshot
       - `onSettled`: invalidate transactions.list query

    3. For split transactions (where `txn.splitCount > 0`): show "Split (N)" text with a click handler to open the split modal, instead of the CategoryPicker.

    4. Add a small "Split" button/link next to the category picker on each row that opens the SplitModal for that transaction.

    **Create SplitModal.tsx:**

    Props:
    - `transaction: { id: string; amount: number; payee: string }` — the transaction being split
    - `onClose: () => void` — close the modal

    Implementation:
    - Modal overlay (fixed position, semi-transparent background, centered white card)
    - Header showing transaction payee and total amount (use `formatCurrency`)
    - A list of split rows, each with:
      - A `CategoryPicker` for selecting the category
      - An amount input (display as dollars, store as cents). Use a text input that accepts decimal values and converts to cents on blur.
    - "Add Split" button to add another row
    - Show remaining amount: `transaction.amount - sum(split amounts)`. Display in red if non-zero.
    - "Save" button that:
      - Validates all splits have a category selected
      - Validates sum of split amounts equals transaction amount (absolute value)
      - Calls `trpc.transactions.createSplits.mutate` with the splits
      - Invalidates transactions.list query
      - Closes the modal
    - "Remove Splits" button (only shown if transaction already has splits) that calls `trpc.transactions.deleteSplits.mutate` and closes
    - "Cancel" button that closes without saving
    - Close on Escape key press
