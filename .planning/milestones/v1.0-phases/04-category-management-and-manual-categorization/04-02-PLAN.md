  <name>Task 2: Build CategoriesPage with full CRUD</name>
  <files>packages/client/src/pages/CategoriesPage.tsx</files>
  <action>
    Create `CategoriesPage.tsx` with:

    **Data fetching:** Use `useQuery(trpc.categories.groups.list.queryOptions())` to load all groups with categories.

    **Layout:** Display category groups as expandable sections (simple collapsible divs with a toggle, not an accordion library). Each group shows its name and a list of categories underneath.

    **Create group:** An "Add Group" button at the top. On click, show an inline text input that creates the group on Enter/blur.

    **Create category:** Each group has an "Add Category" button. On click, show an inline text input within that group.

    **Inline rename:** Clicking a group or category name turns it into an editable text input. On Enter or blur, call the rename mutation. On Escape, cancel.

    **Drag-and-drop reorder:** Install @dnd-kit/core and @dnd-kit/sortable. Use `SortableContext` and `useSortable` for both groups and categories within groups. On drag end, call the appropriate reorder mutation with the new order of IDs. Categories can only be reordered within their group (not across groups).

    **Delete:** Each group and category has a delete button (small X or trash icon). On click, show a `window.confirm()` dialog explaining the impact (e.g., "Delete group 'Housing' and all its categories? Affected transactions will become uncategorized."). On confirm, call the delete mutation.

    **Cache invalidation:** After each mutation (create, rename, reorder, delete), invalidate the `categories.groups.list` query using `queryClient.invalidateQueries()`.

    **Styling:** Use Tailwind classes consistent with the existing pages (gray-50 background, white cards, border-gray-200 borders). Groups have a slightly bolder header. Categories are indented under their group.

    **Empty state:** If no groups exist, show "No categories yet. Create your first category group to get started."

    Install dnd-kit: `npm install @dnd-kit/core @dnd-kit/sortable --workspace=@minerva/client`
  </action>
