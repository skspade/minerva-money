<feature>
  <name>Monarch CSV Parsing, Validation, and Row Transformation</name>
  <files>packages/server/src/import/import-service.ts, packages/server/src/import/import-service.test.ts</files>
  <behavior>
    ## Parsing (parseCsv)
    - Input: raw CSV text string
    - Output: array of raw row objects with Monarch column names as keys
    - Auto-detects delimiter: if first line contains tab, use tab; otherwise comma
    - Strips UTF-8 BOM (U+FEFF) before parsing
    - Normalizes CRLF to LF before delimiter detection
    - Configured with: columns: true, skip_empty_lines: true, trim: true, relax_column_count: true, bom: true
    - Validates required columns exist in header: Date, Merchant, Category, Account, Original Statement, Amount
    - Throws descriptive error if required columns missing
    - Tags column silently ignored; Notes column available for memo

    ## Date Parsing (parseDate)
    - "2024-01-15" -> "2024-01-15" (ISO passthrough)
    - "1/5/2024" -> "2024-01-05" (US short)
    - "01/05/2024" -> "2024-01-05" (US padded)
    - "12/31/2023" -> "2023-12-31" (US end of year)
    - "not-a-date" -> null (unparseable)
    - "" -> null (empty)

    ## Row Validation (validateRow)
    - Input: raw row object, 1-based row number
    - Output: { valid: true } or { valid: false, errors: string[] }
    - Required fields: Date (must be parseable), Amount (must be numeric), Account (non-empty)
    - Merchant OR Original Statement must be non-empty (at least one required for dedup hash payee)
    - Empty/whitespace-only values treated as missing

    ## Row Transformation (transformRow)
    - Input: validated raw row object
    - Output: { date: string, amount: Cents, payee: string, memo: string | null, merchantName: string, categoryName: string, accountName: string }
    - date: parseDate output (YYYY-MM-DD)
    - amount: toCents(parseFloat(row.Amount)) — negative = expense, positive = income (passthrough, no sign flip)
    - payee: "Original Statement" column; falls back to "Merchant" if Original Statement is empty/whitespace
    - memo: "Notes" column mapped; empty/whitespace -> null
    - merchantName: "Merchant" column (preserved for display)
    - categoryName: "Category" column (preserved for mapping)
    - accountName: "Account" column (preserved for mapping)

    ## Amount Edge Cases
    - "19.99" -> 1999 cents
    - "0.01" -> 1 cent
    - "-18.32" -> -1832 cents
    - "0" -> 0 cents
    - "1000.50" -> 100050 cents
  </behavior>

       - `import { parse } from 'csv-parse/sync';` for CSV parsing

       - Export `parseCsv(csvText: string): RawCsvRow[]` — strips BOM, normalizes line endings, auto-detects delimiter, parses with csv-parse, validates required columns
       - Export `parseDate(dateStr: string): string | null` — regex-based, supports YYYY-MM-DD and M/D/YYYY, returns YYYY-MM-DD or null
       - Export `validateRow(row: RawCsvRow, rowNumber: number): ValidationResult` — checks required fields, returns errors with row numbers
       - Export `transformRow(row: RawCsvRow): TransformedRow` — converts to internal format with toCents for amount
       - Define and export TypeScript interfaces: `RawCsvRow`, `TransformedRow`, `ValidationResult`
    4. Use deterministic regex for date parsing — NEVER use `new Date()` or `Date.parse()`
    5. All string field processing: trim values, map empty/whitespace-only to null for nullable fields
  </implementation>
