    - isAccountResolved('acct-123') returns true (real mapping)
    - isAccountResolved('__SKIP__') returns true (skip is resolved)
    - isAccountResolved('') returns false (undecided)
    - filterSkippedAccounts({ Checking: 'acct-1', Savings: '__SKIP__' }) returns { Checking: 'acct-1' }
    - filterSkippedAccounts({ Checking: '__SKIP__', Savings: '__SKIP__' }) returns {}
    - filterSkippedAccounts({ Checking: 'acct-1', Savings: 'acct-2' }) returns unchanged
    - getValidationState with all resolved and at least one real mapping returns { canContinue: true, message: null }
    - getValidationState with some undecided returns { canContinue: false, message: 'All accounts must be mapped or skipped before continuing' }
    - getValidationState with all skipped returns { canContinue: false, message: 'At least one account must be mapped to import' }
    - getValidationState with empty accounts list returns { canContinue: false, message: null }
  </behavior>
  <action>
    1. Define the skip sentinel constant at module scope in ImportPage.tsx:
       ```typescript
       export const SKIP_SENTINEL = '__SKIP__';
       ```

    2. Extract three pure helper functions and export them from ImportPage.tsx for testability:

       ```typescript
       export function isAccountResolved(value: string): boolean
       ```
       Returns true if value is non-empty AND (is a real account ID or is SKIP_SENTINEL).
       Implementation: `return value !== '' && value.length > 0` — since both real IDs and __SKIP__ are non-empty strings, any non-empty value counts as resolved.

       ```typescript
       export function filterSkippedAccounts(mappings: Record<string, string>): Record<string, string>
       ```
       Returns a new record with all entries where value equals SKIP_SENTINEL removed.
       Implementation: `Object.fromEntries(Object.entries(mappings).filter(([_, v]) => v !== SKIP_SENTINEL))`

       ```typescript
       export function getValidationState(
         accounts: { csvName: string }[],
         mappings: Record<string, string>
       ): { canContinue: boolean; message: string | null }
       ```
       Logic:
       - If accounts is empty, return { canContinue: false, message: null }
       - If any account has an empty/unresolved mapping, return { canContinue: false, message: 'All accounts must be mapped or skipped before continuing' }
       - If all accounts are resolved but ALL are __SKIP__, return { canContinue: false, message: 'At least one account must be mapped to import' }
       - Otherwise return { canContinue: true, message: null }

    3. Create ImportPage.test.ts with tests for all three helpers covering the behavior cases above. Import the helpers and SKIP_SENTINEL from ImportPage.tsx.

    4. Run tests to confirm all pass.
