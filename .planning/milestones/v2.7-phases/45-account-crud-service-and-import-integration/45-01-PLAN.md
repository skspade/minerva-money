<feature>
  <name>Account CRUD Service</name>
  <files>packages/server/src/accounts/accounts-service.ts, packages/server/src/accounts/accounts-service.test.ts</files>
  <behavior>
    ## createAccount(db, { name, institution, type? })
    - Creates account with `id = 'manual_' + crypto.randomUUID()`
    - Sets `source = 'manual'`, `balance = 0`, `currency = 'USD'`
    - Type defaults to `'banking'` if not provided
    - Returns full account object: { id, name, institution, type, balance, source, lastSynced }
    - Account appears in `SELECT * FROM accounts WHERE id = ?`

    ## updateAccount(db, id, { name?, institution?, type? })
    - Updates only provided fields (partial update)
    - Returns updated account object
    - Throws TRPCError({ code: 'NOT_FOUND' }) if account doesn't exist
    - Throws TRPCError({ code: 'FORBIDDEN' }) if account.source !== 'manual'
    - Only updates provided fields, leaves others unchanged

    ## deleteAccount(db, id)
    - Deletes the account row
    - FK cascade removes all transactions, balance_snapshots, transfer_links, transaction_splits
    - Throws TRPCError({ code: 'NOT_FOUND' }) if account doesn't exist
    - Throws TRPCError({ code: 'FORBIDDEN' }) if account.source !== 'manual'

    ## recalculateBalance(db, accountId)
    - Sets account.balance = COALESCE(SUM(amount), 0) from transactions
    - Records balance snapshot for today's date (INSERT OR REPLACE)
    - Updates account.last_synced to current timestamp
    - Returns the new balance as integer cents
    - Works correctly with zero transactions (balance = 0)
    - Does NOT open its own transaction (caller manages transaction scope)
  </behavior>
  <implementation>
    1. Create `packages/server/src/accounts/` directory
    2. Create `accounts-service.ts` with all 4 functions
    3. Use `import { randomUUID } from 'node:crypto'` for ID generation
    4. Use `import { TRPCError } from '@trpc/server'` for errors
    5. Import `type Database from 'better-sqlite3'`
    6. Helper: `getAccount(db, id)` private function to fetch and validate account existence + source
    7. Balance snapshot pattern copied from sync-service.ts lines 133-138
    8. recalculateBalance must NOT wrap in db.transaction() -- it runs inside import's transaction
  </implementation>
</feature>
