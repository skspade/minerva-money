3. Create `action-tools.ts` with `createActionTools(db: Database.Database, ctx: Context)` that returns an array of 10 tools:

   **Transaction categorization:**
   - `categorize_transaction`: params `{ transactionId: z.string(), categoryId: z.number() }`. Validate transaction exists (`SELECT id FROM transactions WHERE id = ?`), validate category exists (`SELECT id FROM categories WHERE id = ?`). Call `updateTransactionCategory(db, transactionId, categoryId)`. Return `jsonResult({ success: true, transactionId, categoryId })`.

   **Rule management:**
   - `create_rule`: params `{ name: z.string(), merchantPattern: z.string().nullable().optional(), matchType: z.enum(['exact', 'contains']).optional().default('contains'), amountMin: z.number().nullable().optional(), amountMax: z.number().nullable().optional(), memoPattern: z.string().nullable().optional(), categoryId: z.number() }`. Validate categoryId exists. Call `createRule(db, ...)`. Return `jsonResult({ success: true, rule })`.
   - `update_rule`: params `{ ruleId: z.number(), name: z.string(), merchantPattern: z.string().nullable().optional(), matchType: z.enum(['exact', 'contains']).optional().default('contains'), amountMin: z.number().nullable().optional(), amountMax: z.number().nullable().optional(), memoPattern: z.string().nullable().optional(), categoryId: z.number() }`. Validate ruleId exists (`SELECT id FROM categorization_rules WHERE id = ?`), validate categoryId exists. Call `updateRule(db, ruleId, ...)`. Return `jsonResult({ success: true, ruleId })`.
   - `delete_rule`: params `{ ruleId: z.number() }`. Validate ruleId exists. Call `deleteRule(db, ruleId)`. Return `jsonResult({ success: true, ruleId })`.
   - `apply_rule`: params `{ ruleId: z.number() }`. Validate ruleId exists. Call `applyRule(db, ruleId)`. Return `jsonResult({ success: true, ruleId, transactionsAffected: count })`.

   **Budget adjustments:**
   - `set_budget_allocation`: params `{ categoryId: z.number(), period: z.string(), amountInCents: z.number() }`. Validate categoryId exists, validate amountInCents >= 0. Call `setAllocation(db, categoryId, period, amountInCents)`. Return `jsonResult({ success: true, categoryId, period, amountInCents })`.
   - `set_default_allocation`: params `{ categoryId: z.number(), amountInCents: z.number() }`. Validate categoryId exists, validate amountInCents >= 0. Call `setDefaultAllocation(db, categoryId, amountInCents)`. Return `jsonResult({ success: true, categoryId, amountInCents })`.

   **Transfer management:**
   - `confirm_transfer`: params `{ linkId: z.number() }`. Call `confirmTransfer(db, linkId)` (it throws if not found). Return `jsonResult({ success: true, linkId })`.
   - `dismiss_transfer`: params `{ linkId: z.number() }`. Call `dismissTransfer(db, linkId)` (it throws if not found). Return `jsonResult({ success: true, linkId })`.

   **Sync:**
   - `trigger_sync`: no params `{}`. Call `await runSync(db, ctx.client, ctx.rateLimiter)`. Return `jsonResult(result)`.

   All tools use try/catch wrapping with `errorResult(error)` on failure. Tool descriptions should be concise and action-oriented (e.g., "Categorize a transaction by setting its category. Requires valid transactionId and categoryId.").
