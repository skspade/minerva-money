  <name>Task 1: Create query tools factory with 6 core financial tools</name>
  <files>packages/server/src/agent/tools/query-tools.ts</files>
  <action>
Create `packages/server/src/agent/tools/query-tools.ts`:

Import `tool` from `@anthropic-ai/claude-agent-sdk`, `z` from `zod`, type `Database` from `better-sqlite3`, and service functions.

Export `createQueryTools(db: Database.Database)` returning an array of tool definitions:

1. **get_account_balances** — No inputs.
   - Description: "List all accounts with current balances. Use to answer questions about account balances. Amounts in cents (integer). Account types: checking, savings, credit, investment."
   - Handler: Query `SELECT id, name, institution, type, balance, available_balance FROM accounts ORDER BY institution, name`. Return JSON array.

2. **get_budget_summary** — Input: `{ period: z.string().describe("Month in YYYY-MM format, e.g. '2026-03'") }`.
   - Description: "Get budget status for a month showing allocated, spent, available, and rollover per category. Use for budget questions. Amounts in cents."
   - Handler: Call `getBudgetSummary(db, args.period)`. Also call `getAvailableToBudget(db, args.period)`. Return JSON object with `{ categories: [...], availableToBudget: number }`.

3. **get_spending_by_category** — Input: `{ startDate: z.string().describe("Start date YYYY-MM-DD"), endDate: z.string().describe("End date YYYY-MM-DD") }`.
   - Description: "Get spending breakdown by category for a date range. Use for 'how much did I spend on X?' questions. Amounts in cents (positive = spending). Excludes transfers."
   - Handler: Call `getSpendingByCategory(db, args.startDate, args.endDate)`. Return JSON array.

4. **get_spending_over_time** — Input: `{ startDate: z.string().describe("Start date YYYY-MM-DD"), endDate: z.string().describe("End date YYYY-MM-DD") }`.
   - Description: "Get monthly spending totals over a date range. Use for trend questions like 'am I spending more this month?' Amounts in cents."
   - Handler: Call `getSpendingOverTime(db, args.startDate, args.endDate)`. Return JSON array.

5. **get_net_worth** — Input: `{ startDate: z.string().optional().describe("Start date YYYY-MM-DD (optional)"), endDate: z.string().optional().describe("End date YYYY-MM-DD (optional)") }`.
   - Description: "Get net worth over time with daily data points. Use for net worth and wealth trend questions. Amounts in cents."
   - Handler: Call `getNetWorth(db, args.startDate, args.endDate)`. Return JSON array.

6. **get_available_to_budget** — Input: `{ period: z.string().describe("Month in YYYY-MM format") }`.
   - Description: "Get the amount available to budget (unallocated income) for a period. Use for 'how much can I still budget?' questions. Amount in cents."
   - Handler: Call `getAvailableToBudget(db, args.period)`. Return JSON with `{ period, availableToBudget }`.

For ALL tools:
- Wrap handler in try/catch; on error return `{ isError: true, content: [{ type: "text", text: "Error: " + sanitized message }] }`
- Return data as `{ content: [{ type: "text", text: JSON.stringify(data) }] }`
- Do NOT wrap bank-sourced strings in these tools (no merchant names here — that's for transaction tools in Plan 03)
