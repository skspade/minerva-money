   - Import `query` from `@anthropic-ai/claude-agent-sdk`
   - Import `createMcpServer` from `./mcp-server.js`
   - Import `getSystemPrompt` from `./system-prompt.js`
   - Import type `Database` from `better-sqlite3`
   - Export async function `chat(db: Database.Database, message: string, sessionId?: string): Promise<{ response: string; sessionId: string }>`
   - Implementation:
     a. Call `createMcpServer(db)` to get a fresh MCP server per request
     b. Call `getSystemPrompt()` to get system prompt with current date
     c. Build query options: `{ model: "claude-sonnet-4-20250514", systemPrompt, mcpServers: { minerva: mcpServer }, allowedTools: ["mcp__minerva__*"], maxTurns: 10 }`
     d. If sessionId provided, add `resume: sessionId` to options
     e. Iterate `query({ prompt: message, options })` async generator
     f. Capture `session_id` from system init message (`msg.type === "system" && msg.subtype === "init"`)
     g. Capture final text: if `msg.type === "result" && msg.subtype === "success"`, use `msg.result`
     h. Return `{ response: resultText, sessionId: resultSessionId }`
