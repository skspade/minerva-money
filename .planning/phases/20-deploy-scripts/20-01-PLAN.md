  <action>
  Modify the SIGTERM handler (line 50-54) in packages/server/src/index.ts:

  Replace:
  ```typescript
  process.on('SIGTERM', () => {
    stopSyncScheduler();
    stopBudgetScheduler();
    server.close();
  });
  ```

  With:
  ```typescript
  process.on('SIGTERM', () => {
    stopSyncScheduler();
    stopBudgetScheduler();
    const forceExit = setTimeout(() => process.exit(0), 5000);
    forceExit.unref();
    server.close(() => process.exit(0));
  });
  ```

  The `forceExit.unref()` prevents the timeout from keeping the event loop alive if server.close() completes before 5 seconds. The callback ensures process exits with code 0, preventing KeepAlive from treating a clean deploy restart as a crash.
