  <files>packages/client/index.html, packages/client/src/styles/app.css</files>
  <action>
1. In `packages/client/index.html`, change the viewport meta tag from:
   `<meta name="viewport" content="width=device-width, initial-scale=1.0" />`
   to:
   `<meta name="viewport" content="width=device-width, initial-scale=1, viewport-fit=cover" />`
   This enables `env(safe-area-inset-*)` CSS functions on iPhone (LAYOUT-01).

2. In `packages/client/src/styles/app.css`, add a `pb-safe` utility class after the `@import "tailwindcss"` line using Tailwind v4's `@layer utilities` pattern:

```css
@import "tailwindcss";

@layer utilities {
  .pb-safe {
    padding-bottom: env(safe-area-inset-bottom, 0px);
  }
}
```

This creates the `pb-safe` class used by BottomTabBar and MoreSheet in Plan 02 (LAYOUT-02). The fallback `0px` means it has no effect on non-notched devices.

Do NOT add `pt-safe` or other safe area utilities — only `pb-safe` is needed for Phase 21.

2. **Desktop nav visibility**: Add `hidden md:block` to the `<nav>` element (NAV-03). The full `<nav>` must be hidden on mobile, not just the links div. This prevents the dark nav bar from showing on mobile with just the title visible.
   Change: `<nav className="bg-gray-900 text-white">`
   To: `<nav className="hidden md:block bg-gray-900 text-white">`

3. **Main content padding**: Add `pb-20 md:pb-6` to `<main>` (LAYOUT-03). The `pb-20` (80px) provides clearance for the fixed bottom tab bar on mobile. The `md:pb-6` restores normal padding on desktop.
   Change: `<main className="mx-auto max-w-6xl px-4 py-6">`
   To: `<main className="mx-auto max-w-6xl px-4 py-6 pb-20 md:pb-6">`

4. **Overflow prevention**: Add `overflow-x-hidden` to the root div to prevent horizontal scroll at 375px (LAYOUT-05).
   The root div becomes: `<div className="min-h-dvh bg-gray-50 overflow-x-hidden">`
