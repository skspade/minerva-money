Create `packages/client/src/components/MoreSheet.tsx` with:

- Import `Drawer` from `vaul`
- Import `NavLink`, `useLocation` from `react-router`
- Import `useEffect` from `react`
- Import icons from `lucide-react`: `CreditCard`, `Tag`, `Sliders`, `ArrowLeftRight`, `BarChart`

Define MORE_LINKS array:
```

{ to: '/transfers', icon: ArrowLeftRight, label: 'Transfers' }

```

Props interface: `{ open: boolean; onClose: () => void }`

Component structure:
- Call `useLocation()` to get `location`
- `useEffect` that calls `onClose()` when `location.pathname` changes (NAV-05). Dependency array: `[location.pathname]`. This is intentional — the eslint exhaustive-deps warning about `onClose` can be suppressed with an inline disable comment.
- Render `<Drawer.Root open={open} onOpenChange={(o) => !o && onClose()}>` containing:
  - `<Drawer.Portal>`
    - `<Drawer.Overlay className="fixed inset-0 bg-black/40 z-50" />`
    - `<Drawer.Content className="fixed bottom-0 inset-x-0 z-50 bg-white rounded-t-2xl pb-safe">`
      - Drag handle: `<div className="mx-auto w-12 h-1.5 bg-gray-300 rounded-full mt-3 mb-4" />`
      - `<nav className="px-4 pb-6 space-y-1">`
        - Map over MORE_LINKS rendering `<NavLink>` for each with:
          - Classes: `flex items-center gap-3 px-3 min-h-[44px] rounded-lg text-gray-700 hover:bg-gray-100`
          - Render `<Icon size={20} />` and `<span className="text-base font-medium">{label}</span>`

Export as default.

- NavLink `isActive` provides automatic active state highlighting (NAV-04)
