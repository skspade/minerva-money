  <action>
Add inline editing to the allocated column in BudgetPage.tsx.

**Click-to-edit behavior:**
- Each category's allocated cell is clickable. Clicking it replaces the formatted currency text with an input field.
- Track editing state per category: `editingCategoryId: number | null` in component state.
- When editing starts, show an input field pre-filled with the dollar amount (allocated cents / 100, formatted as a plain number like "150.00").
- Input auto-focuses and selects the full value on mount (use `useRef` and `useEffect`, same pattern as InlineEdit in CategoriesPage).

**Save behavior:**
- Enter key or blur: parse the dollar input as a float, multiply by 100, round to get integer cents. Call `budget.allocations.set` mutation with `{ categoryId, period, amount: centsValue }`.
- Escape key: cancel editing, restore original display, clear editingCategoryId.
- If input is empty or NaN on save attempt, cancel instead.

**Mutation setup:**
- Use `useMutation(trpc.budget.allocations.set.mutationOptions({ onSuccess: () => { queryClient.invalidateQueries({ queryKey: trpc.budget.summary.queryKey() }); } }))`.
- On mutation error: show a brief error message (a simple `<div>` that auto-dismisses after 3 seconds using setTimeout, positioned near the top of the page with `text-red-600 bg-red-50 p-2 rounded`). The invalidation on success ensures the grid re-fetches correct server values. On error, the query cache still holds the old value so the display naturally reverts when the query refetches.

**Optimistic update approach:**
- After the user submits a new value, immediately clear the editing state so the grid re-renders.
- Call `queryClient.invalidateQueries` to trigger a background refetch.
- The TanStack Query refetch replaces stale data with the server's response. On success this confirms the new value; on error it reverts to the pre-mutation state.
- This is simpler than manual optimistic cache manipulation and sufficient because the query is fast.

**Input styling:**
- Input field: `w-24 px-2 py-1 border border-blue-400 rounded text-sm text-right focus:outline-none focus:ring-2 focus:ring-blue-500`
- Match the allocated column width so the layout doesn't shift.
