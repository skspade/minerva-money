**Step 1: Create migration file** `packages/server/migrations/009-chat-history.sql`:

```sql
CREATE TABLE chat_conversations (
  id TEXT PRIMARY KEY,
  title TEXT NOT NULL,
  model TEXT NOT NULL,
  sdk_session_id TEXT,
  created_at TEXT NOT NULL DEFAULT (datetime('now')),
  updated_at TEXT NOT NULL DEFAULT (datetime('now'))
);

CREATE TABLE chat_messages (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  conversation_id TEXT NOT NULL REFERENCES chat_conversations(id) ON DELETE CASCADE,
  role TEXT NOT NULL,
  content TEXT NOT NULL,
  tool_calls TEXT,
  created_at TEXT NOT NULL DEFAULT (datetime('now'))
);

CREATE INDEX idx_chat_messages_conversation_created ON chat_messages(conversation_id, created_at);
```

Replace all `throw new Error('Not implemented')` stubs with real implementations:

**generateTitle(message: string): string**
```typescript
const trimmed = message.trim();
if (!trimmed) return 'New conversation';
if (trimmed.length <= 60) return trimmed;
const truncated = trimmed.slice(0, 60);
const lastSpace = truncated.lastIndexOf(' ');
if (lastSpace > 0) return truncated.slice(0, lastSpace) + '...';
return truncated + '...';
```

**createConversation**: Use `crypto.randomUUID()` for id, `generateTitle(firstMessage)` for title. INSERT and then SELECT back the created row to get server-generated timestamps.

**appendMessage**: INSERT into chat_messages, then UPDATE chat_conversations SET updated_at = datetime('now') WHERE id = conversationId. Use `toolCalls ? JSON.stringify(toolCalls) : null` for the tool_calls column.

**listConversations**:
```sql
SELECT c.id, c.title, c.model, c.created_at, c.updated_at,
  (SELECT COUNT(*) FROM chat_messages WHERE conversation_id = c.id) AS message_count
FROM chat_conversations c
ORDER BY c.updated_at DESC
```

**getConversation**: First query conversation row. If not found, return null. Then query all messages. Parse tool_calls with `JSON.parse()` when non-null.

**deleteConversation**: `DELETE FROM chat_conversations WHERE id = ?`, return `result.changes > 0`.

**renameConversation**: `UPDATE chat_conversations SET title = ? WHERE id = ?`, return `result.changes > 0`.

**purgeOldConversations**: `DELETE FROM chat_conversations WHERE updated_at < datetime('now', '-' || ? || ' days')`, return `result.changes`. Note: SQLite parameterization doesn't work for date modifiers — construct the modifier string safely: `datetime('now', '-${retentionDays} days')` using template literal in the SQL string (retentionDays is a number, safe from injection).
