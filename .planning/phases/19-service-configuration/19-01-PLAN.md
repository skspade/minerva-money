  <name>Task 1: Change server plist KeepAlive from bare boolean to dict form</name>
  <files>deploy/com.minerva.server.plist</files>
  <action>
In `deploy/com.minerva.server.plist`, replace the bare KeepAlive boolean:

```xml
<key>KeepAlive</key>
<true/>
```

With the dict form that only restarts on non-zero exit codes:

```xml
<key>KeepAlive</key>
<dict>
    <key>SuccessfulExit</key>
    <false/>
</dict>
```

This is the ONLY change to make in this file. Do not modify any other keys. The dict form means:
- `SuccessfulExit: false` = "keep alive when SuccessfulExit is false" = restart only on non-zero exit
- Clean shutdown (exit code 0 from server.close() in SIGTERM handler) will NOT trigger restart
- Crash (unhandled exception, non-zero exit) WILL trigger restart

After editing, validate the XML:
```bash
plutil -lint deploy/com.minerva.server.plist
```
