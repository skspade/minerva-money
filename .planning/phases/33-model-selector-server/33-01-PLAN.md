   ```typescript

   ```

   ```typescript

     model: z.string().optional(),
   }))
   ```

   ```typescript
   .mutation(async ({ ctx, input }) => {

       });
     }
     return chat(ctx.db, ctx, input.message, input.sessionId, input.model as ModelId | undefined);
   }),
   ```

   Note: The `as ModelId | undefined` cast is safe because we just validated with isValidModelId. Import `type ModelId` from models.ts if needed for the cast.
