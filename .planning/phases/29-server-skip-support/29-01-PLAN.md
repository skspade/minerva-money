  <files>packages/server/src/import/import-service.ts, packages/server/src/import/import-service.test.ts</files>
  <behavior>
    ## executeImport Changes

    1. When accountMappings omits a CSV account name, the row is skipped (not inserted) instead of throwing an error
    2. skippedByAccountFilter counts rows skipped due to unmapped accounts
    3. skippedCount continues to count only dedup-skipped rows (INSERT OR IGNORE conflicts)
    4. Mapped account rows import normally even when other accounts are unmapped
    5. The skip check happens BEFORE generateDedupHash to avoid computing hashes for skipped rows

    Test cases:
    - executeImport with partial mappings: 2 accounts in CSV, only 1 mapped -> imports mapped rows, skips unmapped
    - skippedByAccountFilter equals number of rows from unmapped accounts
    - skippedCount still tracks dedup skips independently
    - Existing test "rejects when account mapping is incomplete" -> UPDATE to verify it succeeds with skippedByAccountFilter instead of throwing

    ## PreviewResult Changes

    6. rowCountByAccount is a Record<string, number> mapping CSV account names to valid row counts
    7. Computed from validTransformed rows grouped by accountName

    Test cases:
    - previewImport returns rowCountByAccount with correct counts per account
    - rowCountByAccount counts only valid rows (invalid rows excluded)

    ## Type Changes

    8. ExecuteResult gains skippedByAccountFilter: number
    9. PreviewResult gains rowCountByAccount: Record<string, number>
