3. **Create `chat-cleanup-scheduler.ts`** following the sync-scheduler.ts pattern exactly:
   - `import { Cron } from 'croner';`
   - `import type Database from 'better-sqlite3';`
   - `import { purgeOldConversations } from './chat-history-service.js';`
   - `import { homedir } from 'node:os';`
   - `import { join } from 'node:path';`
   - `import { unlink } from 'node:fs/promises';`
   - Module-level `let job: Cron | null = null;`
   - `export function startChatCleanupScheduler(db: Database.Database): void` that:
     - Creates a Cron with expression `'0 0 3 * * *'` (daily at 3 AM — note croner uses 6-field format with seconds first)
     - In the callback (async):
       - Read `CHAT_RETENTION_DAYS` from `process.env` at execution time, `parseInt()`, default 90 if missing/NaN
       - Log: `[chat-cleanup] Running cleanup (retention: ${retentionDays} days)`
       - Call `purgeOldConversations(db, retentionDays)` to get `{ deletedCount, sessionIds }`
       - For each sessionId, construct the file path: `join(homedir(), '.claude', 'projects', encodedCwd, sessionId + '.jsonl')` where `encodedCwd` is `process.cwd().replace(/[^a-zA-Z0-9]/g, '-')`
       - Call `await unlink(filePath)` in a try-catch: swallow ENOENT errors silently, log warning for other errors: `[chat-cleanup] Warning: failed to delete session file ${filePath}: ${err.message}`
       - Log result: `[chat-cleanup] Purged ${deletedCount} conversations, cleaned ${successCount} session files`
     - Wrap entire callback in try-catch with `console.error('[chat-cleanup] Cleanup failed:', err.message)`
     - Log on startup: `[chat-cleanup] Started: purging old conversations daily at 3:00 AM`
   - `export function stopChatCleanupScheduler(): void` that stops and nulls the job, logs `[chat-cleanup] Stopped`
