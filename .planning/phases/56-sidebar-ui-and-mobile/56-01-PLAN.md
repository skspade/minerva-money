<feature>
  <name>Feature: Sidebar display helper functions</name>
  <files>packages/client/src/utils/chat-sidebar-helpers.ts, packages/client/src/utils/chat-sidebar-helpers.test.ts</files>
  <behavior>
    ## formatRelativeTime(dateString: string): string
    - Input within last 60 seconds -> "Just now"
    - Input 5 minutes ago -> "5m ago"
    - Input 2 hours ago -> "2h ago"
    - Input yesterday (same time) -> "Yesterday"
    - Input 3 days ago -> "3d ago"
    - Input 8 days ago -> "Mar 20" (short month + day format, no year)
    - Input from a different year -> "Mar 20, 2025" (includes year)

    ## groupConversationsByRecency(conversations: T[]): { label: string; conversations: T[] }[]
    - Where T has at least { updated_at: string }
    - Groups into ordered buckets: "Today", "Yesterday", "Previous 7 Days", "Older"
    - Empty buckets are omitted from the returned array
    - Conversations within each bucket preserve their original order (already sorted by updated_at DESC from server)
    - A conversation updated 5 minutes ago -> "Today" bucket
    - A conversation updated yesterday -> "Yesterday" bucket
    - A conversation updated 4 days ago -> "Previous 7 Days" bucket
    - A conversation updated 30 days ago -> "Older" bucket
    - Empty input -> empty array

    ## getModelBadge(model: string): { label: string; colorClass: string }
    - "claude-haiku-3-20240307" -> { label: "H", colorClass: "bg-gray-200 text-gray-600" }
    - "claude-sonnet-4-20250514" -> { label: "S", colorClass: "bg-blue-100 text-blue-700" }
    - "claude-opus-4-20250514" -> { label: "O", colorClass: "bg-purple-100 text-purple-700" }
    - Any model containing "haiku" -> H badge
    - Any model containing "sonnet" -> S badge
    - Any model containing "opus" -> O badge
    - Unknown model string -> { label: "?", colorClass: "bg-gray-200 text-gray-600" }
  </behavior>
  <implementation>
    Create `packages/client/src/utils/chat-sidebar-helpers.ts` with three exported functions:

    1. `formatRelativeTime(dateString: string): string`
       - Parse dateString as Date, compute diff from Date.now()
       - < 60s: "Just now"
       - < 60m: `${minutes}m ago`
       - < 24h: `${hours}h ago`
       - If yesterday (comparing calendar dates): "Yesterday"
       - < 7 days: `${days}d ago`
       - Same year: short month + day (e.g., "Mar 20") using Intl.DateTimeFormat or manual month names
       - Different year: short month + day + year (e.g., "Mar 20, 2025")

    2. `groupConversationsByRecency<T extends { updated_at: string }>(conversations: T[]): { label: string; conversations: T[] }[]`
       - Define bucket boundaries using calendar date comparison (start of today, start of yesterday, 7 days ago)
       - Iterate conversations, push into appropriate bucket
       - Filter out empty buckets
       - Return ordered array

    3. `getModelBadge(model: string): { label: string; colorClass: string }`
       - Check model string with `.includes()` for "haiku", "sonnet", "opus"
       - Return corresponding label and Tailwind color class
       - Default to "?" with gray styling

    Tests should use `vi.useFakeTimers()` and `vi.setSystemTime()` for deterministic date testing. Set a fixed "now" and create test dates relative to it.
  </implementation>
</feature>
