  <name>Task 1: Create ConversationSidebar component</name>
  <files>packages/client/src/components/ConversationSidebar.tsx</files>
  <action>
    Create `packages/client/src/components/ConversationSidebar.tsx` with these props:
    ```typescript
    interface ConversationSidebarProps {
      conversationId?: string;
      isStreaming: boolean;
      onClose?: () => void;  // Only used by mobile overlay
    }
    ```

    **Data fetching:**
    - Use `const trpc = useTRPC()` and `useQuery(trpc.chatHistory.list.queryOptions())` to fetch conversations
    - Use `useMutation(trpc.chatHistory.updateTitle.mutationOptions())` for rename
    - Use `useMutation(trpc.chatHistory.delete.mutationOptions())` for delete
    - Get `queryClient` from `useQueryClient()` for cache invalidation

    **State:**
    - `editingId: string | null` -- which conversation is being renamed (null = none)
    - `editTitle: string` -- current value of the rename input

    **Layout (top to bottom):**

    1. **New Chat button** at the top:
       - Full-width button with `SquarePen` icon from lucide-react (matches ChatGPT's compose icon)
       - Text: "New Chat"
       - Classes: `flex items-center gap-2 w-full px-3 py-2.5 rounded-lg text-sm font-medium text-gray-700 hover:bg-gray-100 transition-colors`
       - onClick: `navigate('/chat')` then `onClose?.()`

    2. **Grouped conversation list:**
       - Import `groupConversationsByRecency`, `formatRelativeTime`, `getModelBadge` from `../utils/chat-sidebar-helpers`
       - Call `groupConversationsByRecency(conversations ?? [])` to get groups
       - For each group, render:
         - Group header: `<div className="px-3 pt-4 pb-1 text-[11px] font-semibold uppercase tracking-wider text-gray-400">{group.label}</div>`
         - For each conversation in the group, render a conversation item

    3. **Conversation item** for each conversation:
       - Container: `<div>` or `<button>` with classes:
         - Active (id matches conversationId): `bg-blue-50 border-l-2 border-blue-600 pl-[10px]` (accounting for 2px border)
         - Inactive: `pl-3 hover:bg-gray-100 border-l-2 border-transparent`
         - Common: `flex items-center gap-2 w-full pr-2 py-2 rounded-r-lg text-left transition-colors group cursor-pointer`
         - When `isStreaming && id !== conversationId`: add `opacity-50 pointer-events-none` to disable clicks
       - onClick: `navigate('/chat/${conversation.id}')` then `onClose?.()`
       - Content layout (flex between title area and actions):
         - **Title area** (flex-1, min-w-0 for truncation):
           - If `editingId === conversation.id`: render inline rename input (see below)
           - Else: `<div className="truncate text-sm text-gray-800" title={conversation.title}>{conversation.title}</div>`
           - Below title: `<div className="flex items-center gap-1.5 text-xs text-gray-400">`
             - Relative timestamp: `formatRelativeTime(conversation.updated_at)`
             - Model badge: `<span className={`inline-flex items-center justify-center w-4 h-4 rounded text-[10px] font-bold ${badge.colorClass}`}>{badge.label}</span>` where `badge = getModelBadge(conversation.model)`
         - **Action icons** (visible on hover for inactive, always for active):
           - Container: `flex items-center gap-0.5` with `opacity-0 group-hover:opacity-100` (but always visible if active: no opacity-0)
           - Pencil icon (rename): `<button onClick={startRename} className="p-1 rounded hover:bg-gray-200"><Pencil size={14} /></button>`
           - Trash icon (delete): `<button onClick={handleDelete} className="p-1 rounded hover:bg-red-100 text-gray-400 hover:text-red-600"><Trash2 size={14} /></button>`
           - Stop propagation on icon clicks to prevent navigation

    4. **Inline rename:**
       - When `editingId === conversation.id`, replace title text with:
         ```tsx
         <input
           className="w-full text-sm border border-blue-400 rounded px-1.5 py-0.5 focus:outline-none focus:ring-1 focus:ring-blue-500"
           value={editTitle}
           onChange={(e) => setEditTitle(e.target.value)}
           onKeyDown={(e) => {
             if (e.key === 'Enter') saveRename();
             if (e.key === 'Escape') cancelRename();
           }}
           onBlur={saveRename}
           autoFocus
         />
         ```
       - `startRename(conv)`: set `editingId = conv.id`, `editTitle = conv.title`
       - `saveRename()`: if editTitle.trim() and editTitle !== original title, call `updateTitle.mutate({ conversationId: editingId, title: editTitle.trim() })`, then invalidate list query, then `setEditingId(null)`
       - `cancelRename()`: `setEditingId(null)`

    5. **Delete:**
       - `handleDelete(conv)`: call `window.confirm('Delete this conversation?')`, if confirmed call `deleteMutation.mutate({ conversationId: conv.id })`, invalidate list query
       - If deleted conversation is the active one (`conv.id === conversationId`): `navigate('/chat')`
       - Also call `onClose?.()` on mobile

    6. **Empty state:**
       - If conversations list is empty (after loading): show `<div className="px-3 py-8 text-center text-sm text-gray-400">No conversations yet</div>`

    Export as `default function ConversationSidebar`.
  </action>
