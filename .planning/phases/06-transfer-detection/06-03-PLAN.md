<task type="auto">
  <name>Task 1: Extend transactions.list query with transfer status</name>
  <files>packages/server/src/sync/trpc-router.ts</files>
  <action>
    In the transactions.list query in trpc-router.ts:

    1. Add a LEFT JOIN to detect confirmed transfers. Use a subquery approach for clarity since a transaction could be in either column:

    Add to the SELECT:
    ```sql
    CASE WHEN EXISTS (
      SELECT 1 FROM transfer_links tl
      WHERE (tl.transaction_a_id = t.id OR tl.transaction_b_id = t.id)
      AND tl.confirmed = 1
    ) THEN 1 ELSE 0 END AS is_transfer
    ```

    2. Add `is_transfer` to the row type (as `number`, 0 or 1).

    3. In the return mapping, add `isTransfer: r.is_transfer === 1` (boolean).

    This establishes the pattern that Phase 9 reporting queries will use: any query that computes spending totals will add `AND is_transfer = 0` or the equivalent EXISTS exclusion.
  </action>

    <automated>npx tsc --noEmit</automated>
  </verify>
  <done>transactions.list returns isTransfer boolean for each transaction. Confirmed transfer transactions have isTransfer = true.</done>
