    Create TransfersPage.tsx with two sections:

    **Suggested Transfers section:**
    - useQuery(trpc.transfers.candidates.list.queryOptions()) to fetch candidates
    - Display each candidate as a card showing both transactions side-by-side:
      - Left side: transactionA date, payee, amount (formatted with formatCurrency), accountName
      - Right side: transactionB date, payee, amount, accountName
      - Arrow or transfer icon between them
    - "Confirm" button (green) calls trpc.transfers.confirm mutation with { id: pair.id }
    - "Dismiss" button (gray) calls trpc.transfers.dismiss mutation with { id: pair.id }
    - On mutation success, invalidate both transfers.candidates.list and transfers.confirmed.list queries
    - Empty state: "No suggested transfers" message

    **Confirmed Transfers section:**
    - useQuery(trpc.transfers.confirmed.list.queryOptions()) to fetch confirmed
    - Display confirmed pairs in a similar card layout but with:
      - "Unlink" button (red/outline) calls trpc.transfers.unlink mutation with { id: pair.id }
    - On mutation success, invalidate both query keys plus transactions.list
    - Empty state: "No confirmed transfers" message

    **Manual Link button:**
    - "Link Transfers" button at page top opens ManualLinkModal
    - useState to control modal visibility

    Create ManualLinkModal.tsx:
    - Fetch all transactions via useQuery(trpc.transactions.list.queryOptions())
    - Two selection areas: "Transaction A" and "Transaction B"
    - Each shows a searchable list of transactions (reuse debounced search pattern from TransactionsPage)
    - Each transaction row shows: date, payee, amount, accountName
    - Selected transactions highlighted
    - "Link as Transfer" button enabled when both selected, calls trpc.transfers.manualLink with { transactionAId, transactionBId }
    - On success, invalidate transfer queries, close modal
    - On error, show error message (e.g., same account)
    - Close button / overlay click to dismiss
