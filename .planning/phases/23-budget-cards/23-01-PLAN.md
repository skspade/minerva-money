The card renders:
1. A `<button>` wrapping the card content with `onClick={onToggle}`, `className="w-full text-left px-3 py-3 min-h-[44px]"` (44px touch target)
2. **Row 1**: Category name (left, `font-medium text-sm`) and remaining amount (right, color-coded text: red if `available < 0`, green if `> 0`, gray if `=== 0`)
3. **Progress bar**: A `div` container (`mt-2 h-1.5 bg-gray-100 rounded-full overflow-hidden`) with inner colored div. Width = `Math.min((cat.spent / cat.allocated) * 100, 100)%`. Guard against division by zero: if `allocated === 0`, width is `cat.spent > 0 ? 100 : 0`. Color: `bg-red-500` if `available < 0`, `bg-yellow-400` if `available < allocated * 0.2`, else `bg-green-500`.
4. **Row 2**: Spent/budgeted text (`mt-1 text-xs text-gray-500`): `"{formatCurrency(spent)} of {formatCurrency(allocated)}"`
5. **Expanded section** (only when `isExpanded`): A `border-t border-gray-100 px-3 py-2` div containing an "Allocation" label and `<AllocationCell value={cat.allocated} onSave={onSave} />`

Wrap the whole card in `<div className="bg-white rounded-lg border border-gray-200 shadow-sm">`.
