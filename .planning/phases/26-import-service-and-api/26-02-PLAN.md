  <files>packages/server/src/import/import-service.ts, packages/server/src/import/import-service.test.ts</files>
  <behavior>
    ## previewImport(db, csvText)
    - Parses CSV, validates all rows, transforms valid rows
    - Returns: { totalRows, validRows, sampleRows (first 10 transformed), errors (with row numbers), accounts (unique names with auto-suggested matches), categories (unique names with auto-suggested matches), dedupStats: { newCount, duplicateCount } }
    - Account auto-match: for each unique CSV account name, query `SELECT id, name FROM accounts`, find first where Minerva name contains CSV name (case-insensitive) or CSV name contains Minerva name
    - Category auto-match: for each unique CSV category name, query `SELECT id, name FROM categories`, find first where names match exactly (case-insensitive)
    - Dedup stats: for each valid row with an auto-matched account, compute dedup hash using generateDedupHash(minervaAccountId, date, amount, payee), then batch-check `SELECT dedup_hash FROM transactions WHERE dedup_hash IN (...)` — rows with existing hash are duplicates
    - Rows without auto-matched accounts are counted as "new" in dedup stats (conservative estimate)

    ## executeImport(db, csvText, accountMappings, categoryMappings)
    - accountMappings: Record<string, string> (CSV account name -> Minerva account ID)
    - categoryMappings: Record<string, number> (CSV category name -> Minerva category ID)
    - Validates ALL unique CSV account names have a mapping; throws TRPCError(BAD_REQUEST) if any unmapped
    - Re-parses CSV, validates, transforms (stateless)
    - Wraps ALL inserts in db.transaction(() => { ... })() for atomicity
    - For each valid row: generate UUID via crypto.randomUUID(), compute dedup hash with mapped account ID, INSERT OR IGNORE, track new IDs
    - Set pending = 0 for all imported transactions
    - After inserts: categorizeNewTransactions(db, newTransactionIds)
    - After rules: applyCsvCategoryFallback — UPDATE transactions SET category_id = ? WHERE id = ? AND category_id IS NULL (only for transactions with mapped categories that rules didn't categorize)
    - After category fallback: detectTransferCandidates(db, newTransactionIds)
    - Returns: { importedCount, skippedCount (duplicates), categorizedByRules, categorizedFromCsv }

    ## Test cases:
    - previewImport with valid CSV returns correct counts and sample rows
    - previewImport auto-suggests account matches (substring, case-insensitive)
    - previewImport auto-suggests category matches (exact, case-insensitive)
    - previewImport dedup stats correctly identify existing transactions
    - executeImport inserts transactions atomically
    - executeImport skips duplicates and reports skip count
    - executeImport rejects when account mapping is incomplete
    - executeImport runs rules engine on imported transactions
    - executeImport applies CSV category as fallback (not overriding rules)
    - executeImport runs transfer detection
  </behavior>
