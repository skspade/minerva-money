<feature>
  <name>Express SSE Chat Stream Handler</name>
  <files>packages/server/src/agent/chat-stream-handler.ts, packages/server/src/agent/chat-stream-handler.test.ts, packages/server/src/index.ts</files>
  <behavior>
    ## Input Validation (SRVR-02)
    - Missing message field returns 400 JSON: `{ error: "..." }` with Zod validation message
    - Empty string message returns 400 JSON error (z.string().min(1))
    - Invalid model ID returns 400 JSON: `{ error: "Invalid model: xyz. Valid models: ..." }`
    - Non-JSON body returns 400 (Express json middleware handles this)

    ## SSE Response Format (SRVR-01)
    - Valid request sets response headers: Content-Type: text/event-stream, Cache-Control: no-cache, Connection: keep-alive
    - Calls res.flushHeaders() to send headers immediately
    - Each SSEEvent from chatStream is written as `data: ${JSON.stringify(event)}\n\n`
    - After generator completes, calls res.end()

    ## Abort Handling
    - Creates AbortController, wires req.on('close') to controller.abort()
    - Passes signal to chatStream()
    - If chatStream throws unexpectedly (defense-in-depth), writes SSE error event then res.end()

    ## Route Registration
    - POST /api/chat/stream registered in index.ts before SPA catch-all
    - Handler receives db and ctx via closure from createChatStreamHandler factory
  </behavior>
  <implementation>
    1. Create chat-stream-handler.ts exporting createChatStreamHandler(db, ctx) that returns an Express RequestHandler
    2. Inside the handler:
       a. Parse and validate body with Zod schema: { message: z.string().min(1), sessionId: z.string().optional(), model: z.string().optional() }
       b. If validation fails, return res.status(400).json({ error: formatted Zod error })
       c. If model provided and !isValidModelId(model), return res.status(400).json({ error: `Invalid model: ${model}. Valid models: ${MODELS.map(m => m.id).join(', ')}` })
       d. Set SSE headers (Content-Type, Cache-Control, Connection), call res.flushHeaders()
       e. Create AbortController, wire req.on('close', () => controller.abort())
       f. Iterate chatStream(db, ctx, message, signal, sessionId, model) with for-await, write each event as `data: ${JSON.stringify(event)}\n\n`
       g. After loop, call res.end()
       h. Wrap iteration in try/catch — on error, write SSE error event then res.end()
    3. In index.ts, import createChatStreamHandler and register: app.post('/api/chat/stream', createChatStreamHandler(db, ctx))
       Place this AFTER express.json() middleware but BEFORE the SPA catch-all.
       Specifically, add it right after the tRPC middleware registration block, before const clientDist line.
  </implementation>
</feature>
