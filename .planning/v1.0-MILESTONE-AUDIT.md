## Integration Report

### Broken Flows (2)

1. **User sets default monthly allocation (BUDG-05/BUDG-06)**
   - Break point: UI layer — no UI component calls `budget.defaults.set`
   - Impact: Auto-funding scheduler is inert because defaults table is always empty
   - Server API exists and is tested; only the client UI is missing

2. **launchd-triggered iCloud backup (INFR-01)**
   - Break point: `com.minerva.backup.plist` references `packages/server/src/backup/run-backup.ts` which does not exist
   - Impact: Scheduled backups via launchd fail silently
   - `createBackup()` function works correctly via sync-triggered path (INFR-02)

### Data Display Issue

3. **Spending reports off-by-one (REPT-01/REPT-02)**
   - `getSpendingByCategory` and `getSpendingOverTime` use `t.date < ?` (strict less-than)
   - Callers pass today's date as endDate → today's transactions excluded from charts
   - Fix: use `<=` in query or pass endDate + 1 day from UI
